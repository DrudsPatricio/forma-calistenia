# FORMA — Calistenia pessoal

Aplicação web responsiva de treino de calistenia para iniciantes, feita com React + Vite.

## Executar localmente

1. Instale Node.js (versão LTS) em https://nodejs.org/
2. Abra um terminal dentro da pasta do projeto.
3. Execute `npm install`
4. Execute `npm run dev`
5. Abra o endereço local mostrado pelo Vite.

## Publicar gratuitamente na Vercel

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta.
2. Entre em https://vercel.com/ e conecte sua conta GitHub.
3. Selecione **Add New → Project** e importe o repositório.
4. A Vercel deve detectar Vite automaticamente. Build command: `npm run build`; output directory: `dist`.
5. Clique em **Deploy**. A Vercel fornecerá um endereço `.vercel.app`.

## Observações
- O progresso é salvo em `localStorage` no navegador deste dispositivo. Não há sincronização entre dispositivos nem backup em nuvem.
- O cronômetro funciona enquanto a página está aberta. Navegadores podem suspender temporizadores em segundo plano.
- As ilustrações de execução são esquemáticas; leia as instruções e adapte o movimento ao conforto. Interrompa se sentir dor aguda, tontura ou falta de ar incomum.
- As sessões são um ponto de partida geral, não uma avaliação individual de saúde ou condicionamento.
